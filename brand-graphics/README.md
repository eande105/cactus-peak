# Cactus Peak graphics

Vector graphics for the marketing site, the member web app and the iOS app. The graphics are
**images**, not interface icons. Interface icons (buttons, menus, inline glyphs) are Nucleo `ui` outline on the web (`@/components/icons`) and SF Symbols on iOS.

**The brand language is the gym objects** (`VISUAL-IDENTITY.md`): 33 Nucleo core glyphs in five compositions
(Rack, Set, Row, Crop, Tile). Use them for all new work. The line pictograms, scenes, coach marks and bespoke
graphics below are **retiring**: keep them only where a product still uses them, and do not add new uses.

## Gym objects

| File | Contents |
|---|---|
| `nucleo-art.ts` | Generated by `scripts/import-nucleo-objects.mjs` from Nucleo core, glyph, 48 px. Do not edit |
| `objects.ts` | Labels and meanings, the category map, the club Sets and the general set |
| `compose.ts` | `rack`, `row` (Set and Row), `crop`, `tile` |
| `scheme.ts` | Colour schemes: `sand`, `night`, `copper`, and `{ category }` for Tiles; CSS and hex resolvers |

```tsx
import { ObjectRack, ClubSet, ObjectRow, ObjectCrop, CategoryTile, GymObject } from "@/components/brand/graphics"

<div className="relative aspect-[4/3]"><ObjectRack ratio="4/3" fill /></div>     // hero image slot, Night
<ObjectRack ratio="21/9" ids={clubObjects["mesa-dobson"]} seed={3} />             // club header, wall layout
<ObjectRack ratio="4/3" layout="orbit" scheme="copper" focus="pool" fill />    // section card (also cluster, arc,
                                                                                   // spotlight, hub, climb, stagger, frame, fade)
<ClubSet club="gilbert-val-vista" className="w-28" />                              // beside the club name, always
<ObjectRow ids={["plate", "wave", "paddle", "spin-bike"]} />                       // a plan's contents
<ObjectCrop id="pool" ratio="1/1" />                                             // a section point, with a real figure
<CategoryTile category="aqua" className="size-8" />                                // class rows and filters
<CategoryTile category="strength" cut className="size-32" />                       // empty state
<GymObject id="whistle" scheme="night" />                                          // one object in brand colours
```

Props: `scheme` (`"sand"`, `"night"`, `"copper"`), `label` (accessible name; without it the graphic is
`aria-hidden`), `fill` (fill a positioned parent), `className`, `style`. Pass the container's real `ratio` to
`ObjectRack` and `ObjectCrop`; they compose for it and never stretch. `seed` keeps a Rack stable; use a
different seed for two Racks on one page.

Exports: `svg/objects/<id>-<mode>.svg` (brand colours, transparent ground, 256 px) and
`svg/category/<category>[-cut]-<mode>.svg` (category colour, bare or in the cut tile). iOS: add each pair to
the asset catalog as one image set with Any and Dark appearances; build Racks in SwiftUI from the object images.

## Space and class graphics: line collection

The space graphics and the class graphics are one collection of line illustrations, designed together.

- **Field:** one flat, very light tint of the tone (10 % of the tone over the page sand, `--neutral-3`).
  In dark mode the same mix gives a very dark tint. No skyline, ribs, floor or second shape.
- **Subject:** a duotone line drawing in one hue. Outlines and small solid parts (plates, handles, hubs,
  a ball's holes, a kite's bows) use the tone's full value. Main surfaces (a kettlebell body, a mat,
  locker doors, pool water) use the mid tint: 32 % of the tone over the page sand in light mode and
  56 % in dark mode, so field, fill and line are three clear steps in both themes. Fills share the path
  of their outline, so they always stay inside it. Round caps and joins.
- **Realism:** each subject follows a real product's proportions in one clean view (side, front or
  three-quarter). See `components/brand/graphics/references.md`.
- **Margins:** the subject's 48-unit box takes 56 % of the short side, so about 22 % stays clear on each
  side. The optical size is the same at every ratio, and nothing touches the edges.
- **Stroke rule (one rule):** the stroke does not scale with the viewBox. Its width follows the rendered
  width: `clamp(1.75px, 1.684px + 0.329cqi, 3.25px)`, which gives 2 px at 96 px and 3 px at 400 px.
  The component wraps the SVG in an inline-size container and draws the strokes with
  `vector-effect: non-scaling-stroke`. The export script writes the same rule as a fixed width for each
  file's export size (`hairPx` in `sets.ts`).
- **Subjects:** spaces show the place or its equipment (rack, cable stack, treadmill, mat and block,
  studio bike, net, pool ladder, thermometer, fountain, sauna bucket, children's slide, lockers, deck rail
  and sun, agility ladder with cones, cup). Classes show the activity or its tool (kettlebell, road bike, stopwatch, stones,
  drop, paddle and ball, foam roller, kite). No subject is in both sets.
- `detail="simple"` drops secondary lines (ticks, louvres, slats) for 96 px and smaller and keeps the fills.

## Coach marks and space art: the same line style

Coach marks and space art use the line style above: the tint field, the same stroke rule, strong outlines,
mid-tint surfaces and one hue per piece.

- **Coach marks** use more solids: the largest shapes are filled in the strong tone or the mid tint, so
  each mark reads as a compact emblem at 40 px. The subject's 48-unit box takes 60 % of the mark, well
  inside the circle crop.
- **Space art** shows scenes: several real objects in a real space. A wall line, a floor line and floor
  seams in one-point perspective place the scene; there are no filled floor bands or skylines. Repeats
  (windows, mirror panels, lanes, bikes, balusters) are counted from the width, objects keep their
  proportions, and side objects drop out when the frame is narrow. The main object sits on the centre.
- **Night** (cycle studio, Downtown, Devon Hart) draws in Saguaro Night on the light field, lightened in
  dark mode, so the line style keeps its contrast.

## Visual language (bespoke graphics)

- **Flat tonal fields, no gradients.** Each piece uses one tone and a six-step ramp of it (f0 faint
  field to f5 full tone), plus `paper` (cut-outs) and `ink` (thin metal parts).
- **Rib-peak geometry.** Backgrounds are cut into upright ribs with pleat gaps, and their tops follow
  60° slopes, the way the Rib Peak symbol is cut. Rib counts follow the width. They never mean
  "the five clubs", and they never replace or redraw the logo.
- **One bold subject.** Few parts, upright strokes, 60° and 90° angles. No people, no silhouettes,
  no flexed arms, lightning, flames or skulls.

`paper` is light in both themes: `--neutral-1` in light mode and `--neutral-10` in dark mode (the
components set it with a `.dark .cpg` rule). Normal tones mix the tone into `--neutral-1`. Night mixes
paper into `--night`, so a night piece is a dark green block with light shapes in both themes. In dark mode the variables change, so every
graphic follows the theme with no extra code. Never hard-code hex in a product; use the component
(web) or the `-light` / `-dark` file pair (iOS).

## Aspect ratio

Each piece is composed for the ratio it is shown at. The canvas is always 100 units high and
100 × ratio wide. Bands and repeats (ribs, lane floats, balusters) span the real width, the floor line
and focal x move by ratio class (wide ≥ 1.9, landscape ≥ 1.2, square ≥ 0.9, tall), and subjects are
placed with a uniform scale. Nothing is stretched. If the container differs a little from the ratio you
pass, `preserveAspectRatio="xMidYMid slice"` crops the edges. Pass the ratio of the container.

## Marketing site (React)

```tsx
import { SpaceGraphic, ClassGraphic, CoachMark, SpaceArt, BrandGraphic } from "@/components/brand/graphics"

<SpaceGraphic id="lap-pool" ratio="4/3" />                 // club "spaces and amenities" cards
<SpaceGraphic id="lap-pool" ratio={1} detail="simple" />   // 96 px tile
<ClassGraphic id="cycle" ratio="16/9" />                   // Home carousel slide (tone = category colour)
<ClassGraphic id="cycle" ratio={1} />                      // class grid card
<CoachMark slug="imani-brooks" size={120} />               // circle crop, 40–200 px
<SpaceArt id="exterior-mesa-dobson" ratio="21/9" />        // photo slot replacement
<div className="relative aspect-[4/5]"><SpaceArt id="studio" ratio="4/5" fill /></div>
<BrandGraphic id="switchback" shape="square" />            // empty state
```

Shared props: `tone` (override), `label` (accessible name; without it the graphic is `aria-hidden`),
`detail` (`"full"` or `"simple"`), `fill` (fill a positioned parent), `className`, `style`.
Give a `label` only when the graphic carries meaning that the text beside it does not.

## Web app

Copy or import the files from `svg/` and render them with `<img>`. Pick the file by the user's colour
mode, for example with `<picture>` and `prefers-color-scheme`, or by the app's theme class. Use `alt=""`
when a text label sits beside the graphic. If the web app adopts React with the same tokens, copy the
`components/brand/graphics` folder instead and get live theming.

## iOS app

Add the SVG pairs to the asset catalog as one image set with an "Any" and a "Dark" appearance
(`*-light.svg` and `*-dark.svg`). Check "Preserve Vector Data". Use the `tile` and `thumb` variants
below 120 pt. Crop coach marks with `.clipShape(Circle())`. Mark the image as decorative
(`.accessibilityHidden(true)`) when the name is shown beside it.
