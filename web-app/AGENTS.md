## Backend

The app reads and writes Supabase. Read `../supabase/README.md` first (tables, row level security, functions, demo logins), and the "Backend" section of `BUILD-NOTES.md` for how auth, the catalog and the member store work here. Never add a service or secret key to this app.

## UI and theme

For UI work, follow GUI.md and use graphical-ui, graphical-convert, or graphical-audit as appropriate. The skills are in `.agents/skills/`.

This app already runs the Graphical theme through the bundled runtime in `components/graphical/` (from an earlier full-component install). Use its exports from `@/components/graphical`. Keep the runtime's internal `--theme-name` (`Base`). The newer guidance-only files in `gui/` show the display name there, but the runtime uses `Base` to select component behavior.

The `shadcn` skill, the `shadcn` MCP server and the `next-devtools` MCP server are set up for this project (`.mcp.json`, `.claude/skills/`). Use the shadcn tools to look up docs and registry items. GUI.md wins on styling and component choice. Do not run `shadcn add` for a component that already wraps Graphical (`components/ui/button`, `accordion`, `input`, `separator`, and the overlay and control wrappers): it would overwrite the Graphical version. The app `Button` keeps its `loading` prop.

## Icons

**Project override (Oct 29, 2026): Nucleo replaces Lucide.** This project's icon pack is Nucleo Pro, `ui` family,
outline style, 18 px grid (licensed to the project owner). Import interface icons from `@/components/icons`. The
module is generated by `marketing-site/scripts/import-nucleo-icons.mjs` from the local Nucleo install
(`~/.nucleo/skills`); to add an icon, add it to `ICONS` in that script and run it. Do not import `lucide-react`
in app code. Do not change the icon code inside `components/graphical/` or `components/ui/`: those components keep
their bundled icons, and `components/graphical-theme-provider.tsx` routes the Graphical icon names to Nucleo through
`IconRendererProvider` (a name without a Nucleo match keeps the bundled Lucide icon). Brand graphics (the gym
objects) are a separate system: see `../VISUAL-IDENTITY.md`.

for logos and brand rules, not a token source: this project's theme, specs, and rules still win for UI colour,
tokens, and type.
